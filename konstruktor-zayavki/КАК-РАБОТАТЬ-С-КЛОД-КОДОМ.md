<a id="1"></a>
## 1. Что такое Claude Code и зачем он нужен

Claude Code — это тот же самый Клод, с которым вы общаетесь на
сайте claude.ai, но запущенный **прямо на вашем компьютере**,
в терминале. Разница:

| На сайте claude.ai | В Claude Code на компьютере |
|---|---|
| Работает в браузере | Работает в чёрном окне-терминале |
| Не видит ваши файлы, пока не прикрепите | Видит все файлы в папке проекта |
| После окончания сеанса ничего не остаётся | Ваши файлы остаются на компьютере |
| Правки сохраняет только у себя в Artifact | Правит исходники прямо в папке |
| Чтобы передать правки — надо копировать | Правки сразу «живые» |

Для нашей задачи — конструктор заявки — Claude Code удобнее,
потому что:
- Вы один раз установите, и дальше можно открывать его когда угодно.
- Он видит все 17 файлов проекта сразу.
- Он сам запускает `python build.py` после каждой правки.
- История изменений остаётся у вас (можно делать резервные копии).

## 2. Как установить Claude Code на Windows

### Шаг 2.1. Проверить, установлен ли уже

Нажмите `Win + R`, в появившемся окне наберите `cmd` и нажмите Enter.
Откроется чёрное окно — это и есть «терминал» или «командная строка».

Введите:

```
claude --version
```

и нажмите Enter.

- Если выдало что-то вроде `claude-code 1.x.x` — **Claude Code уже
  установлен**, переходите сразу к шагу 3.
- Если выдало `'claude' is not recognized...` — надо установить,
  идём дальше.

### Шаг 2.2. Установить Node.js (если не стоит)

Claude Code работает поверх Node.js. Это как «движок»,
на котором он запускается.

Проверка — в том же терминале:

```
node --version
```

- Если вышло `v20.x.x` или выше — Node.js есть, идём к шагу 2.3.
- Если `'node' is not recognized...` — надо установить.

**Установка Node.js:**
1. Откройте в браузере: <https://nodejs.org/en/download>
2. Скачайте «Windows Installer (.msi)», версия **LTS** (жёлтая кнопка).
3. Запустите скачанный файл, жмите «Далее» со всеми настройками по умолчанию.
4. **Важно**: во время установки должна быть галочка «Add to PATH» —
   обычно она стоит по умолчанию.
5. Закройте терминал и откройте заново (чтобы он подхватил новую
   установку). Проверьте снова: `node --version`.

### Шаг 2.3. Установить Claude Code

В терминале введите:

```
npm install -g @anthropic-ai/claude-code
```

и нажмите Enter.

Начнётся установка — обычно 1-2 минуты. Пойдут строки с
прогрессом. В конце должна быть строка с версией.

Проверьте:

```
claude --version
```

Если выдало версию — всё, установлено.

### Шаг 2.4. Авторизоваться

Запустите в терминале:

```
claude
```

При первом запуске он попросит войти в аккаунт Anthropic.
Откроется страница в браузере — войдите тем же аккаунтом, которым
пользуетесь на claude.ai.

Если спросит, какую тарифную модель использовать (API ключ или
подписка) — выбирайте «подписку Claude» (login with Claude account),
это бесплатно в рамках вашего плана claude.ai.

<a id="3"></a>
## 3. Как открыть терминал

Два простых способа, оба каждый раз.

**Способ А — через меню Пуск:**
1. Нажмите `Win` (кнопка Windows).
2. Наберите `cmd` или `powershell`.
3. Enter.

**Способ Б — быстро через «Выполнить»:**
1. `Win + R`.
2. Наберите `cmd`.
3. Enter.

Откроется чёрное окно с мигающим курсором. Это и есть терминал.

Что видно внутри: что-то вроде

```
Microsoft Windows [Version 10.0.19045.3570]
(c) Microsoft Corporation. All rights reserved.

C:\Users\Radik Sadykov>
```

Строка `C:\Users\Radik Sadykov>` — это «подсказка». Она показывает,
в какой папке вы сейчас. По умолчанию — в вашей домашней.

<a id="4"></a>
## 4. Как перейти в папку с проектом

Все действия начинаются с того, что вы в терминале «входите»
в папку проекта. На каждом запуске это надо делать заново.

Команда:

```
cd "%USERPROFILE%\Desktop\konstruktor-zayavki"
```

Разбор:
- `cd` — change directory, «перейти в папку».
- Кавычки нужны, потому что в пути есть пробел (`Radik Sadykov`).
- `%USERPROFILE%` — Windows подставит сюда `C:\Users\Radik Sadykov`.

Можно и прямо:

```
cd "C:\Users\Radik Sadykov\Desktop\konstruktor-zayavki"
```

Нажмите Enter. Подсказка станет:

```
C:\Users\Radik Sadykov\Desktop\konstruktor-zayavki>
```

Это значит — вы на месте.

**Проверить, что всё правильно:** введите `dir` и Enter — покажет
список файлов в текущей папке. Должны увидеть `README.md`,
`CLAUDE.md`, `build.py`, `data`, `site` и т.д.

**Лайфхак:** можно открыть папку в проводнике, в адресной строке
скопировать путь, и в терминале написать `cd "`, вставить путь,
закрыть кавычку и Enter.

<a id="5"></a>
## 5. Как запустить Claude Code

Когда вы в папке проекта, просто введите:

```
claude
```

и Enter.

Он запустится и покажет приглашение — что-то вроде:

```
   ✻ Welcome to Claude Code!
   
   /help for help, /status for your current setup
   
   cwd: C:\Users\Radik Sadykov\Desktop\konstruktor-zayavki
```

Снизу — поле для ввода ваших сообщений. Можно писать по-русски.

**Важно:** когда он открывается, он автоматически читает файл
`CLAUDE.md` в папке. Там уже написано, что это за проект, что
где лежит, какие правила. Поэтому ему **не надо снова объяснять**
про ВИКИНГ, 17025, 7 плиток и т.д. — просто пишите, что надо
поменять.

<a id="6"></a>
## 6. Как общаться с ним — что он понимает

Пишите обычным русским языком, короткими фразами.

**Примеры хороших запросов:**

- *«Открой `site/body.tpl` и покажи, где описана первая плитка»*
  → он откроет файл и покажет нужное место.

- *«Переименуй плитку 'Косметология / салоны' в 'Салоны красоты'»*
  → он сам найдёт нужные строки в `app.js` и `body.tpl`, поменяет
  и пересоберёт.

- *«Добавь в пресет 'Смывы ПО' показатель 'Enterobacter sakazakii'
  с методом ГОСТ ISO 29981-2013»*
  → он откроет `data/env.json`, найдёт нужный пресет, добавит
  строку.

- *«В разделе IV убери галочку про цветность воды»*
  → он найдёт в `body.tpl` блок IV, уберёт нужный `<label>` и в
  `app.js` подчистит обработчик.

- *«Поменяй цвет кнопки 'Далее' на зелёный»*
  → откроет `head.tpl`, поменяет переменную `--accent` или нужный
  класс.

- *«Собери проект заново»* или *«Запусти build.py»*
  → выполнит `python build.py`.

- *«Покажи, как сейчас выглядит шапка страницы»*
  → откроет `site/head.tpl` и `site/body.tpl`, зачитает.

- *«Отмени последнюю правку»*
  → откатит, если недавно делал.

**Что он спросит:**

Перед тем как изменять файл, он покажет диф (что уберёт, что
добавит) и спросит: разрешаете? Отвечайте:
- `y` или Enter — да, применить.
- `n` — нет, не применяй.
- `e` — хочу отредактировать его правку сам.

Это важная «страховка»: ничего не поменяется, пока вы не одобрите.

**Что писать НЕ надо:**
- Не надо давать ему ссылки на сайт claude.ai artifact — он с
  них не читает. Все данные уже в папке.
- Не надо копировать-вставлять содержимое файлов — он сам
  открывает что нужно.

<a id="7"></a>
## 7. Что он делает с вашими файлами

Все изменения — прямо в папке `konstruktor-zayavki`. Никаких
копий «где-то в облаке».

Обычный ход правки:
1. Вы пишете, что поменять.
2. Он читает нужные файлы.
3. Показывает, какие строки хочет изменить (в формате: красным —
   старое, зелёным — новое).
4. Спрашивает: разрешаете?
5. Если `y` — записывает в файл.
6. Если это файл-исходник (app.js / body.tpl / head.tpl / данные),
   он **сам** запускает `python build.py`, чтобы пересобрать
   `site/index.html`.
7. Говорит: «готово».

**Файлы, которые он правит:**
- `site/app.js` — логика
- `site/body.tpl` — HTML
- `site/head.tpl` — стили
- `site/memo.html`, `site/lab.html` — тексты вкладок
- `data/catalog_final.json` — продукты
- `data/env.json` — пресеты (смывы, вода, воздух…)
- `data/tr_rows.json` — ТР ТС
- `CLAUDE.md`, `README.md` — документация проекта

**Файлы, которые он НЕ должен править руками:**
- `site/index.html` — результат сборки
- `site/app.built.js` — тоже результат сборки

Они пересобираются сами из исходников.

<a id="8"></a>
## 8. Как посмотреть результат (открыть страницу в браузере)

Два варианта.

**Способ 1 — двойной клик.**
Откройте в проводнике папку `konstruktor-zayavki\site`, найдите
`index.html` и двойной клик по нему. Откроется в вашем браузере
по умолчанию.

**Способ 2 — попросить Claude Code открыть.**
Прямо в его окне напишите:

```
Открой site/index.html в браузере
```

Он выполнит команду `start site\index.html`.

Если видите страницу — отлично, всё работает. После каждой правки
просто обновляйте страницу (`F5` или `Ctrl+R`).

<a id="9"></a>
## 9. Как сохранить историю изменений (git) — опционально

Это **необязательно**, но очень полезно: с git вы можете в любой
момент откатиться на любой момент прошлого. Как «машина времени»
для папки.

### Установить git (если не стоит)

Проверка:
```
git --version
```

Если ошибка — скачайте с <https://git-scm.com/download/win>,
установите с настройками по умолчанию.

### Инициализировать репозиторий в проекте

Один раз, при первом сеансе Claude Code в этой папке, попросите:

```
Инициализируй git-репозиторий и сделай первый коммит с текущим состоянием
```

Он выполнит:
```
git init
git add .
git commit -m "Первая версия конструктора"
```

### Делать «точки сохранения» по ходу работы

После каждой заметной правки:

```
Сделай коммит с сообщением "Переименовала плитку салоны красоты"
```

Он сделает `git commit`.

### Если что-то сломалось — откатить назад

```
Покажи историю коммитов
```

Он покажет список правок с номерами. Чтобы откатиться:

```
Откати состояние на коммит с сообщением "..."
```

<a id="10"></a>
## 10. Частые проблемы и как их решить

### `'claude' is not recognized`
Claude Code не установлен или не в PATH. Шаг 2.3 ещё раз.

### `'python' is not recognized`
Python не установлен. Поставьте с <https://python.org/downloads/>,
при установке галочка «Add Python to PATH» обязательно.

### Claude Code завис / не отвечает
`Ctrl+C` в его окне — прервёт текущую операцию. Если не помогает,
закройте окно терминала и откройте заново. Всё, что вы сохранили,
останется в файлах.

### Он сделал правку, а в браузере не видно
Нажмите `F5` или `Ctrl+F5` в браузере — обновите страницу. Если
не помогло — попросите «пересобери build.py». Если и это не
помогло — закройте вкладку браузера и откройте `site/index.html`
заново.

### Хочу вернуть, как было до правки
Если делали git-коммиты (п. 9) — попросите откатить. Если нет —
попросите «отмени правку такую-то». Если и этого не осталось в
памяти Claude Code — можно восстановить из прошлой версии папки,
если делали бэкап.

### Хочу сохранить все эти изменения, но на другом компьютере работать с теми же файлами
Скопируйте всю папку `konstruktor-zayavki` на флешку / в облако
(Яндекс.Диск, Google Диск) / на почту. На другом компьютере
скачайте, положите в удобное место и `cd` туда.

<a id="11"></a>
## 11. Полезные команды внутри Claude Code

Команды со слешем вводятся в его окне (не в терминале Windows):

| Команда | Что делает |
|---|---|
| `/help` | Список всех команд |
| `/status` | Показать, где вы, какая модель, сколько токенов |
| `/clear` | Начать разговор с чистого листа (память предыдущих правок стирается, но файлы остаются) |
| `/compact` | Сжать историю разговора, чтобы освободить место |
| `/review` | Обзор, что менялось в этом сеансе |
| `/exit` или `Ctrl+D` | Выйти из Claude Code |

## Короткая шпаргалка — один раз утром

```
1. Win + R  →  cmd  →  Enter
2. cd "%USERPROFILE%\Desktop\konstruktor-zayavki"
3. claude
4. Пишете, что поменять. Разрешаете правки (y).
5. Обновляете site/index.html в браузере, смотрите.
6. (Опционально) просите сделать коммит.
7. /exit  когда закончили.
```

Удачи. Если застряли — просто спросите Клода в веб-чате
«застряла на шаге N инструкции», он подскажет.
