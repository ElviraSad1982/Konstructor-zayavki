# Конструктор заявки — ИЛ ООО «ВИКИНГ»

Веб-страница для заказчиков: помогает заполнить заявку на лабораторные
испытания (ГОСТ ISO/IEC 17025 п. 7.1) и акт отбора, не разбираясь в
нормативной базе.

## Что внутри папки

```
konstruktor-zayavki/
├── README.md         ← это руководство
├── CLAUDE.md         ← заметки для Claude Code
├── build.py          ← скрипт сборки (Python 3)
├── data/             ← данные, только читаются
│   ├── catalog_final.json  (229 продуктов, 28 категорий)
│   ├── env.json            (45 пресетов: смывы, вода, воздух, …)
│   ├── tr_rows.json        (строки ТР ТС 021/033/051 и др.)
│   ├── fx_raw.json         (ФХО из ОА — пока в резерве)
│   └── shpargalka.xlsm     (шпаргалка ВИКИНГ от 17.09.2026)
└── site/             ← исходники страницы
    ├── app.js        ← вся логика (главный файл для правок)
    ├── body.tpl      ← HTML-разметка страницы
    ├── head.tpl      ← стили, фавикон, Google-шрифт
    ├── memo.html     ← вкладка «Памятка»
    ├── lab.html     ← вкладка «Для лаборатории»
    ├── hero.webp     ← инфографика в шапке
    ├── index.html    ← СОБРАННАЯ страница (её открываете в браузере)
    └── app.built.js  ← собранный JS (не редактировать вручную)
```

## Как работать

### 1. Открыть и посмотреть, что получилось

Двойной клик на `site/index.html` — страница откроется в браузере.
Все изменения из `app.js`, `body.tpl`, `head.tpl` попадают сюда
только после пересборки.

### 2. Запустить сборку (после правок)

Нужен **Python 3** (проверить: `python --version` в терминале).

Из корня папки `konstruktor-zayavki/`:

```
python build.py
```

Выведет:
```
1/4  Читаю исходники…
2/4  Загружаю данные (catalog_final, env, tr_rows)…
       продуктов: 229, строк TR ТС: ...
3/4  Собираю app.built.js и index.html…
4/4  Готово.
       Открывайте: .../site/index.html
```

### 3. Что править чаще всего

| Что меняем | В каком файле |
| --- | --- |
| Текст плиток и подкатегорий (HoReCa / Бассейн / …) | `site/app.js`, константы `MODES` и `SUBS` |
| Разделы IV, V, цели испытаний, кто отбирает пробы | `site/body.tpl` и `site/app.js` (`printHTML`) |
| Шапка, цвета, шрифт | `site/head.tpl` |
| Памятка для заказчика | `site/memo.html` |
| Инструкция для сотрудников лаборатории | `site/lab.html` |
| Данные по продукту (показатели, НД, методики) | `data/catalog_final.json` |
| Данные по смывам / воде / воздуху | `data/env.json` |
| Нормы ТР ТС 021 / 033 / 051 | `data/tr_rows.json` |

Правило: **не трогайте `app.built.js` и `index.html` руками** — они
перегенерируются из исходников при каждом `python build.py`.

### 4. Как публиковать как Artifact в claude.ai

Файл `site/index.html` — самодостаточный: все данные, стили и скрипты
внутри. Его можно:
- открыть локально (двойной клик);
- загрузить на любой хостинг как `index.html`;
- опубликовать через Claude в чате — попросите «опубликуй как Artifact
  вот этот index.html».

## Если что-то сломалось

1. Проверьте, что Python 3 стоит: `python --version`.
2. Запустите `python build.py` — ошибка будет указывать на файл.
3. Если нужно откатиться — просто перескачайте папку из прошлой
   версии (или в git откатитесь на предыдущий коммит, если
   инициализировали репозиторий).
